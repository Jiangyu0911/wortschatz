## Wortschatz 1.34

两件事：**拼写对错改成悬浮提示**，**首页新增「复习安排」**。

### 一、拼写对错改为悬浮

原来判定结果是一条随页面排版的横幅：出现时把题目、输入框、变音字母按钮整体往下推，
消失时又推回去。字体小、键盘弹起时版面本来就紧，这一下位移很明显。

现在改成浮层：

- 卡片飘在顶部操作条下方，**不占布局**——判定前后页面元素位置完全不变
- 从上方滑入并淡入，自动淡出：答对停 2.2 秒（够看清复数），答错停 4.5 秒（要记住正确答案）
- 带投影，背景不透明（浮层若半透明，背后的题目文字会透出来，看着像渲染错位）
- 位置让过「跳过 / 检查」按钮，不与操作按钮重叠

### 二、首页「复习安排」

首页在「今日任务」下方新增一张卡片：

- 今天 / 明天 / 后天各有多少词到期，今天有量时用主色点亮
- 前三天都是 0 时（间隔 4 天起很常见），底部直接写「下次复习：周六 11月7日 · 141 个」，
  避免三个 0 被看成「没有复习任务」
- 点卡片进入**复习安排页**：按天分组的完整计划，每天标出日期与词数，
  每个词给出德语、释义、等级和当前间隔（`隔 4 天` / `学习中`）

数据来自每个词的遗忘曲线到期时间；**已逾期未复习的并入「今天」**——对用户来说
它们此刻就是要补的，单列一个「逾期」区反而要先想一下才明白。

### 三、实测

- 首页：`今天 0 / 明天 0 / 后天 0` + `下次复习：周六 11月7日 · 141 个（未来 7 天共 190 个）`
- 详情页：`周六 11月7日  141 个`，词条显示 `der Mann / 男人；丈夫 / A1 / 隔 4 天`
- 拼写页答错：红色浮卡 `正确答案：Café / 复数 die Cafés`，题目与输入框位置不动，2 秒后淡出
- 拼写页答对：绿色浮卡 `拼写正确 / 复数 die Restaurants`，进度 2/20，卡片不压按钮
- 逾期词归入「今天」：上一轮未复习完的 9 个词显示在「今天」分组
