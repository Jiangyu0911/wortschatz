## Wortschatz 1.31

本次只改一件事：**撤销从底部提示条改成「摇一摇手机」**，摇动后弹确认框，由你决定要不要回退。

### 一、为什么改

原来每做一次可撤销操作（评价卡片、收藏、答题、删导入词…），底部就会浮出一条
「已加入生词本 · 撤销」的提示条。问题有三个：

1. **占地方**。它必须参与布局，不能盖住内容，于是学习页、拼写页、导入页都得给它留一条高度；
   拼写页键盘弹起后本来就紧，多这一条就把按钮挤到屏幕外。
2. **要用手去够**。学习时手在屏幕下半区打分，撤销按钮贴在最底部，误触一次就得移动手指。
3. **一直在动**。6 秒后自动淡出，列表滚动时也在闪，看着烦。

改成摇一摇后，撤销不再占据任何布局空间，页面高度完整还给内容。

### 二、怎么用

- 做完一个操作后**摇一下手机**（45 秒内有效）
- 手机会先轻轻震一下（表示手势被识别），随后弹出确认框：
  「撤销这一步？—— 评了「认识」」，两个按钮「不用了 / 撤销」
- 点「撤销」回退那一步；点「不用了」或点框外则保持原样

### 三、细节

- **只有存在可撤销操作时才监听传感器**：没有可撤销内容时摇动不会有任何反应，
  也不耗电；走路时手机晃动不会莫名弹窗
- **45 秒有效期**：超过这个时间自动失效，避免几分钟后摇一下把早已翻篇的操作回退掉
  （那时界面状态早已不是当时那份快照）
- **单次磕碰不算摇动**：判定依据是「相邻采样的加速度变化率」，需要 600 毫秒内累计
  够次数才算一次摇动；放桌上、手指敲屏幕、走路都不会触发
- **两次触发至少隔 1.5 秒**，避免一次甩动连弹两个框
- 系统设置里新增开关（设置 → 撤销 → 摇一摇手机撤销），可以关掉；
  关掉后没有任何撤销入口
- 首次出现可撤销操作时提示一次「摇一摇手机可以撤销这一步」，之后不再打扰

### 四、顺带

撤销条从四个页面移除（学习页、拼写页、拍照导入、文本导入），页面底部不再有那条黑条。
判定逻辑抽成独立的 `ShakeDetector`，配了 7 个单元测试：静止、走路、磕碰不触发，
轻摇与用力甩要触发，冷却期内不重复触发。

### 实测

- 查词页收藏 Haus → 摇动 → 弹「已移出生词本」→ 点撤销 → 星标回到空心
- 查词页收藏 → 摇动 → 点「不用了」→ 星标保持实心，未回退
- 学习页评价「认识」→ 摇动 → 弹「评了「认识」」→ 点撤销 → 卡片退回 das Mädchen，进度 0/9
- 无可撤销操作（或超过 45 秒）时摇动：无反应、不弹窗
- 设置页关闭「摇一摇手机撤销」后，收藏操作再摇动：无反应
- 单元测试 7/7 通过
