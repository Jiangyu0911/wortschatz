## Wortschatz 1.28

### 打开时先白屏的问题

白屏不是应用画出来的，而是**系统在 App 画出第一帧之前显示的启动窗口**——它用的是主题里的
`windowBackground`（一只近乎纯白的颜色）。于是在进程启动、初始化词库这几百毫秒到几秒里，
用户看到的就是一片白，然后才出现 Compose 画的标识。

现在改用系统级启动画面（AndroidX SplashScreen）：

- 冷启动第一帧之前，系统直接绘制**深蓝底 + 白色 W + 琥珀短线**（与桌面图标同一套图）
- 这套配色与 App 内的启动页一致，系统图撤掉时不会出现白→蓝的跳变
- 交给系统在第一帧后自动撤除启动图，不再手动挂等待条件

### 顺带

- 启动页配色改为品牌深蓝（原先是白底 + 蓝色圆），与图标、系统启动图统一
- 标题与副标题错开 90ms 上浮，进度提示最后浮现

### 实测

冷启动（清空数据后重新灌 10312 条词库）：
0.7 秒时已是深蓝启动页，约 2 秒进首页，全程没有白屏。
热启动 0.45 秒时同样是深蓝启动页。
