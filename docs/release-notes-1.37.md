# Wortschatz 1.37 · 照片更大，词块更小

上一版把识别结果盖在照片上，但有两处比例不对：照片左右各留了 12dp、高度还封顶 460dp，而词块被强制「至少 19dp 高、24dp 宽」。结果照片显得小，词块却比原词大一圈，压住上下行的空白，看着像一片色块贴在书上。

## 改了两处

**照片**：左右只留 4dp，几乎占满屏宽；高度上限改为屏幕的 92%（只为拦住长截图，普通竖拍照片用不到）。照片越大，原词在屏幕上占的像素越多，词块就能贴着原文画而不用放大。

**词块**：严格跟着识别到的原词框走，不再有最小宽高。字号同时按块高与块宽推算，字一定落在块内，最小 5sp。

块变小后不好点，所以外面套了一层透明的点击层，上下左右各外扩 4dp——**视觉不动，热区变大**。
