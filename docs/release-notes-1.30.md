## Wortschatz 1.30

两个功能/修复：**拍照与相册支持多张导入**，以及**拼写测试会"跳过单词"的问题**。

### 一、拼写测试会跳过单词

原因是「检查」和「下一题」用的是**同一个按钮的同一个位置**。判定后按钮立刻变成「继续测试」，
如果手快连点两下（或者键盘上按了回车、又点了按钮），第二下就被当成翻页——
刚提交的词直接翻过去，正确答案根本没看到。实测可复现：输入错误答案后连点两次，
屏幕直接换到下一个词。

修法分两层：

1. **判定后按钮先禁用 600ms 再放开**。这段时间按钮是灰的，连点无效；
   界面上也能看出「按钮刚刚出现」。
2. **跳过也加同样的锁**：之前连点「跳过这个词」会一次跳过两个词。
3. 空输入时「检查」不生效，避免误触把词记成答错。

### 二、拼写：回车提交，结果在顶部

- **回车即提交**：键盘上按「完成 / 回车」等同于点「检查」
- **判定结果移到页面顶部**：绿色的「拼写正确」或红色的「正确答案：xxx」，
  连同复数形式一起显示在题目上方；键盘弹起时下方区域会被遮住，只有这里一定看得见
- **再按一次回车就进入下一个词**，不用去够按钮（错误答案同样适用）
- 判定后视图自动回到顶部，避免此前滚动位置把反馈藏在屏幕外

### 三、拍照 / 相册多张导入

- **相册**：一次可多选，选几张识别几张
- **拍照**：可连续拍，每拍一张追加到当前结果
- 多张图的候选词**合并去重**后统一匹配词库，顺序保持「第一张、第二张…」
- 顶部显示「已识别 N 张图片 · 共 M 个候选词」
- 某张图没认出来时提示「有 N 张图片未能识别，已跳过」，不影响其余

### 四、顺带

拼写页内容改为可滚动：键盘弹起后高度不够时不再把按钮挤到撤销条下面。

### 实测

- 输入 `zzz` → 回车 → 顶部显示「正确答案：Tee / 复数 die Tees」；再按回车进入下一题
- 输入 `Kaffee`（咖啡）→ 回车 → 顶部绿色「拼写正确 / 复数 die Kaffees」，进度 1/20
- 输入 `zzz` → 检查 → 0.3 秒内再点一次：仍停在「正确答案：Brot / 继续测试」，没有跳过；1 秒后再点才正常翻页
- 空输入点检查：无反应，不产生错误记录
- 相册多选两张各 3 词 → 2 张 / 7 个候选（重名的 Kapitel 只入一次）；再追加一张 16 词的图 → 3 张 / 16 个候选；再拍一张 → 4 张
