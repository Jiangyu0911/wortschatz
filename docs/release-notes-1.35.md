# Wortschatz 1.35 · 管理单词时可以搜索删除

自建单词书里词多了以后，翻列表找一个词很费劲，而之前搜索框只用来「找词加入本书」——搜出来的词如果已经在书里，只能看到一个 ✓，没有移出入口。

## 搜索框现在两个方向都能用

输入关键词后，结果分两组：

- **书里的词**：当前这本书里命中的词，右侧是 ✕，点一下即移出
- **其他匹配，点 + 加入**：书外可加入的词，右侧是 +

顶部会写明「书里 2 个（点 ✕ 移出）· 全库另 36 个可加入」，一眼看得出两边各有多少。

## 书里的词不会被搜丢

书内命中的词是**单独在当前书里查的**，不走全库搜索。全库搜索有条数上限，词表大的时候书里的词会被挤到结果之外——词明明在书里却搜不到，也就删不掉。现在按书内词表本地过滤，还支持变音字母互搜（输 `Gemuese` 能找到 `Gemüse`）与中文释义搜索。

## 删错了能撤回

移出后底部提示「已移出，可在「设置」中撤销」。设置页的撤销卡片会写明「从《书名》移出「das Haus」」，点一下这个词就回到书里，耗时不超过 10 分钟都有效。

## 细节

- 搜索无结果时只显示一处「没有匹配的词」（早先版本会同时出现在表头和页面中间）
- 搜索框提示语改为「搜索：书里已有的词可移出，其他词可加入」，不再只讲添加

## 验证

| 场景 | 结果 |
|---|---|
| 书里 1 词，搜索 Haus | 书里的词 1（带 ✕）+ 其他匹配 37 ✓ |
| 加入 der Hauser 后再搜 | 书里的词 2（das Haus、der Hauser），两个都可删 ✓ |
| 删掉 der Hauser | 只剩 das Haus，der Hauser 回到其他匹配并带 +，Toast 提示 ✓ |
| 设置页撤销 | 卡片显示「从《TestBook》移出「der Hauser」」→ 撤销后书回到 2 词 ✓ |
| 搜索 zzz | 单处「没有匹配的词」✓ |
