# Wortschatz 1.38 · 拼写可以选着写冠词与复数

拼写测试原来只要求写出单词本身：`Hund` 对，`der Hund` 也对，冠词被自动忽略；复数完全不参与。想练「性与复数一起记」的人没有出口。

现在设置里有两项可以单独打开。

## 新增两个开关（设置 → 拼写测试）

**要求写冠词**：名词必须写出 der / die / das，漏写或写错算错。`der Hund` 对，`Hund` 错，`die Hund` 错。

**要求写复数**：名词写成「单词, 复数」，如 `der Hund, Hunde`。只写单词、或不写复数都算错；复数带冠词（`die Hunde`）也接受。

两项关掉时与旧版完全一致——默认没有变严格，只是多了一个选项。

## 题面会告诉你格式，但不会给答案

开启后题面多一行「按格式写：der Hund, Hunde」——示例固定用 Hund 这个词，不会泄露当前题的答案；输入框占位也同步变成这个格式。

判错时的答案按当前设置给出，比如开启两项后是「正确答案：die Lektion, Lektionen」，直接能看出缺了哪部分。

## 判定上的几个细节

- **只对名词生效**。动词、形容词没有冠词与复数，开了开关也不受影响。
- **没有复数的词不卡人**。像 der Mut 这类不可数名词，复数要求自动跳过。
- **变音仍可替换**。`das Buch, Buecher` 与 `das Buch, Bücher` 等价，和单词本身的判定规则一致。
- **分隔符宽容**。逗号、分号、斜杠都认；非名词多写了逗号段会被忽略，不会因此判错。

## 用单元测试锁住规则

这类「开关组合」最容易在改动时出问题（明明写对却判错），因此补了 13 个用例：默认宽松、只开冠词、只开复数、两项都开、变音等价、无复数名词、非名词不受影响、答案与格式示例。全部通过。

## 实测

| 场景 | 结果 |
|---|---|
| 开启两项后拼「课」 | 题面显示「按格式写：der Hund, Hunde」✓ |
| 只输入 `Lektion` | 判错，答案 `die Lektion, Lektionen` ✓ |
| 输入 `das Buch, Buecher` | 判对，进度 0/3 → 1/3 ✓ |
| 关闭拼写测试总开关 | 两个子开关隐藏，设置值保留 ✓ |
