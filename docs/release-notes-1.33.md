## Wortschatz 1.33

撤销不再是手势，改成**设置页里的一个按钮**。摇一摇整套实现已经移除。

### 一、为什么又改

上一版给判定加了「方向必须来回翻转」，日常动作已经挡掉大部分，但真机上仍然偏灵——
握着手机走动、放进裤兜、单手握持切换姿势，偶尔还是会被判成摇动，弹出一个不相干的确认框。

问题不在参数，而在**入口本身**：撤销是低频操作（一次学习可能只用一次），
却挂在一个持续监听、随时可能误判的手势上。低频操作不值得占用一个高灵敏度的触发器。

所以改回显式入口——想撤销的时候，去设置页点一下。

### 二、怎么用

**设置 → 撤销**（设置页第一张卡片）

- 有可撤销操作时，卡片上直接写明上一步是什么：`评了「认识」`、`已加入生词本`、`删除了「Kapitel」`…
- 点「撤销这一步」回退，并弹一条「已撤销：…」的提示
- 没有可撤销操作时，卡片显示「暂无可撤销的操作」，按钮置灰
- **10 分钟内有效**（原来 45 秒）：入口藏在设置里，要走几步才点得到，有效期得跟着放宽

### 三、顺带修掉的两个细节

1. **撤销后不会立刻冒出反向的撤销项**。之前撤销「收藏」会触发「取消收藏」，而这步又会
   登记一条新撤销，卡片上立刻出现「已加入生词本」，看着像没撤成功。现在撤销过程中
   产生的登记会被丢弃，撤销完卡片回到「暂无可撤销的操作」。
2. **开始新一轮学习时清空撤销**。上一轮的学习快照对不上新排的队列，留着会让撤销
   把队列换成旧的。

### 四、一并移除的东西

- 摇一摇的手势识别、传感器监听、震动反馈
- `VIBRATE` 权限（应用现在只剩网络相关权限）
- 模拟器摇一摇注入脚本

### 实测

- 设置页初始：「暂无可撤销的操作」，按钮置灰
- 查词页取消收藏 → 设置页显示「已移出生词本」→ 点撤销 → 星标恢复实心，Toast「已撤销：已移出生词本」，卡片回到「暂无可撤销的操作」
- 学习页评价「认识」→ 退出 → 设置页显示「评了「认识」」→ 点撤销 → 重新进入学习，进度与连续认识次数回到评价前
- 撤销后无崩溃，日志无异常
