# Wortschatz 1.36 · 识别结果直接盖在照片上

拍照导入原来是「识别 → 下来一张候选词列表」，要对着照片一行行核对哪个词识别错了，很费眼睛。现在识别结果直接盖在原文上。

## 照片上直接选词

每个识别到的词在原位置生成一个词块，**盖住原来的字**：

- **深蓝实心**：会导入词书，块上写着词库词形（原文 `Häuser` 也可能显示为 `Haus`）
- **空心细框**：不导入，原文露出来，方便对照片原样
- **红色**：词库没有收录这个词，选上并在下方补填释义后才会导入

点一下切换选中与取消，顶部会实时显示「命中 N 个 · 已选 M」和底部「导入 M 个词」。想批量处理时右上角有「全选 / 全不选」。

## 为什么这样更好

早先的做法有两个实际问题：

1. **对不上号**。识别错了通常错在「这个词跟旁边那个粘在一起」或者「把 A 认成 B」，只看列表看不出是哪一处。
2. **虚词占屏**。一页教材里 der / die / das / und 有十几个，列表里都占一行，真正要背的名词被挤到后面。

现在虚词根本不画词块（它们本来也不会进词书），页面上只剩值得看的词。

## 多张照片

一次选多张或连拍，每张照片依次列出，各自的词块独立可点。**同一个词出现在多张图里共享选中状态**——取消一处，其余全跟着取消，最终也只导入一次。

## 下面的细节

- 识别前先按 EXIF 把照片摆正，再把长边缩到 1600px；OCR 与显示用同一张位图，所以词块不会飘到别的词上
- 相册（Photo Picker）返回的地址不适合两次打开流，改成一次性读成字节再解码——这是上一版「图片识别失败」的原因，普通拍照不受影响，所以一直没暴露
- 未收录词面板默认收起，点红色词块会自动展开
- 键盘弹起时输入框和导入按钮会跟着上移；选中的未收录词若没填释义，按钮会写「导入 N 个词 · M 个待填释义」，不会让人以为词丢了

## 验证

| 场景 | 结果 |
|---|---|
| 相机拍 10 行的单词表 | 每个名词盖住原有字，冠词不显示词块 ✓ |
| 点 Haus 词块 | 变空心露出原文，底部从「导入 12 个词」变「导入 10 个词」✓ |
| 点红色未收录词块 | 变实心红块并自动展开补填面板，填释义后计入总数 ✓ |
| 两张照片同选 | 两张分别显示词块，重复出现的 Kapitel 在一处取消、两处同时变空 ✓ |
| 只导入选中的 10 个 | 新书《拍照导入 2》10 词 ✓ |
| 文本导入回归 | 命中 1 + 未收录 1，未填释义不计入导入数量 ✓ |
