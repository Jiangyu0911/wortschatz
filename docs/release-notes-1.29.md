## Wortschatz 1.29

### 拍照 / 相册支持多张导入

之前一次只能处理一张图片，第二张会把上一张的结果覆盖掉。现在改为**按批合并**：

- **相册**：一次可多选，选几张识别几张
- **拍照**：可以连续拍多张，每拍一张就追加到当前结果
- 多张图的候选词会**合并去重**，再统一匹配词库，顺序仍是「第一张、第二张…」的先后
- 顶部显示「已识别 N 张图片 · 共 M 个候选词」，随时知道加了几张

清空 / 撤销都作用于整批结果；如果某张图没认出来（模糊、反光），会单独提示
「有 N 张图片未能识别，已跳过」，不影响其余图片的结果。

### 实测

两张单词表照片（各 3 个词，都含 Kapitel）→「已识别 2 张图片 · 共 7 个候选词」，
命中 7 个且 Kapitel 只出现一次；再从相册追加一张 16 词的图 → 变成 3 张 / 16 个候选，
原有结果保留、新词补齐；再用相机拍一张 → 4 张，全程无重复、无覆盖。
